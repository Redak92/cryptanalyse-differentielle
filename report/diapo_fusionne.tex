\section{Introduction}

\begin{frame}{1. Objectifs de l'étude}

\begin{enumerate}
    \item Modéliser le coût d'une cryptanalyse différentielle exhaustive
    \item Étudier l'effet des S-Box sur un Feistel
    \item Rechercher des clés faibles
\end{enumerate}

\vspace{0.4cm}

\begin{block}{Question centrale}
Une S-Box performante localement améliore-t-elle forcément le chiffrement global ?
\end{block}

\end{frame}

% =====================================================
\section{Méthodologie}

\begin{frame}{2. Structure du Feistel utilisé}

Bloc de 12 bits séparé en deux moitiés de 6 bits.

\vspace{0.3cm}

À chaque round :

\[
L_{i+1}=R_i
\]

\[
R_{i+1}=L_i \oplus F(R_i,K_i)
\]

avec :

\[
F(R_i,K_i)=SBox(R_i \oplus K_i)
\]

\vspace{0.3cm}

\begin{itemize}
    \item $K_i$ : sous-clé dérivée de $K$
    \item S-Box bijective $6 \rightarrow 6$
\end{itemize}

\end{frame}

% =====================================================

\begin{frame}{3. Optimisation par Hill Climbing}

Principe :

\begin{enumerate}
    \item Génération d'une S-Box aléatoire
    \item Échange de deux valeurs
    \item Évaluation du score
    \item Conservation si amélioration
    \item Répétition sur plusieurs milliers d'itérations
\end{enumerate}

\vspace{0.4cm}


\end{frame}

\section{Conclusion}

\begin{frame}{8. Conclusion}

\begin{enumerate}
    \item La complexité suit bien une loi exponentielle
    \item Une bonne S-Box locale ne suffit pas
    \item Optimiser le système complet est plus efficace
    \item Aucune clé faible détectée sur 4096 clés
\end{enumerate}

\vspace{0.5cm}

\begin{block}{Message final}
Un composant cryptographique doit être évalué dans son architecture globale.
\end{block}
